# 같은 노래, 다른 귀

정필 음률학 1편 「같은 노래가 왜 다르게 들릴까」의 부록 앱입니다. 소리를 읽는 세 축(속도·높이·크기)과 뇌의 반응을 직접 만져 보도록 만들었습니다. 같은 선율의 빠르기와 장조·단조를 바꿔 듣는 실험, 맥박 재기, 각성의 거꾸로 된 U, ISO 226:2003 등청감 곡선과 작게 틀면 저음이 빠지는 계산, 다이내믹의 폭, 기대와 절정의 도파민 개념도, 끝음 맞히기 놀이, 가사와 하는 일, 상태에 따라 대역이 바뀌는 수신기 비유, 음악을 고르기 전 세 가지와 하루의 소리 지도를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 속도: 세 개의 축, 같은 선율 다른 빠르기·조성, 맥박 재기, 거꾸로 된 U
- ② 귀의 모양: 등청감 곡선(ISO 226:2003), 작게 틀면 얇아지는 이유, 다이내믹
- ③ 기대하는 뇌: 기대(미상핵)와 절정(측좌핵), 끝음 맞히기, 가사와 하는 일, 수신기 비유
- ④ 소리 지도: 음악을 고르기 전 세 가지, 하루의 소리 지도, 오늘의 핵심

## 계산 기준과 알림
- 원곡은 쓰지 않습니다. 모든 소리는 앱이 직접 지은 짧은 선율을 Web Audio로 만들어 냅니다.
- 등청감 곡선과 '작게 틀면 얇아지는' 계산은 ISO 226:2003 공식(20 Hz~12.5 kHz)으로 구하고, 폰→손 변환은 40폰 이상 2^((P−40)/10), 그 아래는 (P/40)^2.642 근사를 씁니다. 계산에 쓰는 곡은 모든 높이가 같은 세기인 가상 곡입니다.
- 거꾸로 된 U, 도파민 곡선, 수신기 필터(작은 음량 제외), 다이내믹 파형과 dB 값, 각성·기분 표시는 연구 결론을 옮긴 개념 그림이며 측정값이 아닙니다.
- 하루의 소리 지도와 세 가지 확인의 BPM 범위는 앱이 덧붙인 참고값입니다.
- 맥박 재기는 의료 측정이 아니며, 아무것도 저장하거나 보내지 않습니다.
